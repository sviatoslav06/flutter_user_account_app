# Flutter User Account App

This project is a Flutter rewrite of the original React/Vite user account page app. It includes screens for:
- Login
- Registration
- Profile
- Task List
- Schedule
- Dialogs for creating and editing tasks

## Structure
- `/lib/screens/` — main app screens
- `/lib/widgets/` — reusable UI components
- `/lib/dialogs/` — dialogs for tasks
- `/lib/styles/` — global styles and themes

## Getting Started
1. Install Flutter SDK: https://docs.flutter.dev/get-started/install
2. Run `flutter pub get` in the project directory
3. Launch with `flutter run`
